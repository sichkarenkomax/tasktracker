## 1. Тема и компоновка (1.1, 1.2)

- [ ] Открывается золотая тёмная тема (не-синяя), без вспышки смены темы при загрузке.
- [ ] Тема меняется в профиле `/users/me` (рядом с языком), выбор запоминается.
- [ ] Синяя тема — прежняя «как есть»; в золотой — чёрный текст на жёлтом акценте, контраст читается (focus/hover/error состояния в норме).
- [ ] Радиусы панелей/кнопок однородны (~16/8/6px: панели/строки/контролы).
- [ ] Панели не прилегают вплотную к шапке и боковым меню; между соседними секциями есть отступ (шкала 4/8/12/16/24).
- [ ] Нет похожих на дизайн-регрессии на экранах: список задач, карточка задачи, оргструктура, участники, настройки, профили, проекты, страница входа.

## 2. Список и календарь (1.3, 1.4, 1.5)

- [ ] Фильтры задач и формы не используют нативные `<select>` — везде listbox (триггер — кнопка с `role="combobox"`).
- [ ] Listbox: открытие, выбор, Esc, стрелки/Home/End, typeahead, пустой список и disabled — ведут себя разумно.
- [ ] Длинный список (проекты/пользователи) не уплывает за край окна; при нехватке места меню переворачивается вверх.
- [ ] В Chrome и Firefox: у инпутов `date`/`datetime-local` в фокусе нет синей OS-обводки выделенного сегмента (в Chrome — лёгкий тинт акцентом, не коробка).
- [ ] Глиф календаря приглушён, на hover — ярче.

## 3. Навигация (1.6, 1.9)

- [ ] Кнопка «Назад» слева от заголовка на странице проекта и карточки задачи (крошек нет).
- [ ] Прямой заход по ссылке на карточку/проект (без истории) → «Назад» ведёт на родительский список, а не в пустоту.
- [ ] Рельс — ровно 4 раздела: Проекты, Задачи, Сотрудники, Настройки. Активный подсвечен.
- [ ] Подменю-аккордеон: «Задачи» → «Сохранённые фильтры» («Сохранённых фильтров пока нет», пока ничего не сохранено); «Сотрудники» → «Пользователи» и «Оргструктура».
- [ ] Сворачивание/разворачивание по клику на заголовок; chevron поворачивается.
- [ ] Глубокие ссылки: `/users/me` → раздел «Настройки» (подсвечен «Мой профиль»), `/users` → «Сотрудники», `/structure` — авто-открытый «Оргструктура».
- [ ] Пункт «Пользователи» виден только у superuser (у dev-владельца — есть, у обычного участника — нет).

## 4. Сохранённые фильтры (1.9)

- [ ] Сохранить фильтр в фильтре задач (например, «просрочено» = overdue=1) — он появляется в подменю «Сохранённые фильтры» без перезагрузки страницы.
- [ ] Клик по сохранённому фильтру → переход на `/tasks?...`, строка подсвечена.
- [ ] Удаление/пересохранение фильтра с тем же именем — заменяет, подменю обновляется.

## 5. Бургер и мобильные (1.7, 1.8, 1.10)

Проверять на узком окне (`≤960px`) или через DevTools-эмуляцию ~480px.

- [ ] Меню выезжает от края рельса; рельс остаётся видимым и кликабельным, меню его не перекрывает.
- [ ] Анимация плавная (~0.15s), без рывков; закрытие — клик по затемнению (скриму) и по Esc (фокус возвращается на бургер).
- [ ] В DevTools «Emulate prefers-reduced-motion» (или ОС, reduce motion): меню появляется/закрывается без движения.
- [ ] Страница входа `/login` (без входа) — без пустой колонки рельса слева, шапка не сдвигается, бургера нет.
- [ ] На средних разрешениях, где рельс и меню видны одновременно, контент под скримом не дёргается.
